Things I've built

Funding Finder: AI Grant & Sponsor Matching Agent

Agentic AI Workshop, NYU — October 2026

A live, tool-using AI agent that helps nonprofits and startups find funding. It runs a short intake, classifies the applicant, searches a curated funder dataset through tool calls, and returns matches with fit reasoning, award ranges, deadlines, and source links.

I built in safeguards from the start: the agent asks for explicit approval before saving a shortlist or remembering a profile, keeps memory across sessions, and traces every model request and tool call so its behavior can be reviewed.

  • Node.js
  • OpenRouter
  • LLM tool calling
  • Human-in-the-loop
  • Tracing
